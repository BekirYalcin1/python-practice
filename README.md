# Python Practice (Dr. Chuck - Python for Everybody)

This repository contains my beginner Python practice scripts based on Dr. Charles Severance (University of Michigan) **Python for Everybody** course (Getting Started + Data Structures).

## What’s inside
Small exercises to build core programming skills:
- User input + type conversion (`int`, `float`)
- Conditionals (`if/elif/else`)
- Loops (`for`, `while`)
- Functions (`def`, `return`)
- Basic error handling (`try/except`)
- Strings (search, slicing, `split`, `find`)
